# 表計算 / Graph Studio

添付の仕様書 v1.0 に基づく表計算・グラフ編集 Web アプリです。表計算と Graph Studio が同じデータを共有し、セル変更にグラフ・数学・解析オブジェクトが連動します。

ヘッダーとロゴは表示しません。画面切替・ファイル操作はコンパクトなメニューに集約しています。Studio の操作画面は無彩色のダークテーマです。グラフ自体の配色はテーマ・系列の設定に従います。

## 起動

Node.js 22.12 以降を使用します。

```bash
cd /workspace/Graph-editor
npm ci
npm start
```

起動時に esbuild でビルドし、ポート `5173` で配信します。`PORT=5180 npm start` で変更できます。開発中の変更は `npm run build` 後にブラウザーを再読み込みしてください。`npm run dev` もビルド・起動を実行します。

## Cloudflareへのデプロイ

Workersのデプロイコマンドは `npx wrangler deploy` です。`wrangler.jsonc` がビルド `npm run build` を先に実行し、生成した `dist` を配信します。Cloudflare側のビルドコマンドが空欄でも動作します。詳しい設定と白画面の修正内容は [Cloudflare配信手順](docs/CLOUDFLARE.md) を参照してください。

## 操作

- 表計算: ダブルクリック・F2・文字入力で編集、Enter/Tab/矢印で移動、ドラッグ・Shiftで範囲選択。数式・絶対/相対/別シート参照、コピー＆ペースト、オートフィル、複数シート、行列挿入削除、書式・結合・条件付き書式、検索置換、ソート・フィルター・固定、行列サイズ変更に対応します。
- グリッドはスクロールに合わせて表示領域を入れ替えます。名前ボックスに `AA100` のように入力して直接移動できます。下部の矢印で表示範囲も切り替えられます。
- グラフはセル範囲の先頭行を系列名、先頭列をX値・カテゴリとして解釈します。「データ」からX列、系列列、誤差のセル範囲を指定できます。
- Studio の「グラフ」には16形式、「テーマ」には48テーマがあります。テーマの構成要素の組合せ、用途・カテゴリ・検索・お気に入り・最近使った、カスタムテーマ保存・単独入出力に対応します。
- テーマ切り替えは、線幅・点の大きさと形・棒の角丸と幅・文字組み・グリッド・軸・凡例・背景面・余白をまとめて適用します。フラット／かわいい／科学／製図／エディトリアルなどで形そのものが変わります。選択後の個別調整と、調整したデザイン全体のカスタム保存・入出力も可能です。詳しくは [テーマの描画ルール](docs/THEMES.md) を参照してください。
- パネルのタイトルをドラッグし、作業領域の左右・上下・中央へドロップすると、ドック／タブへ配置できます。タイトルをダブルクリックすると最大化／復帰します。「設定」ではフロート・非表示・配置保存／復元と、各ツールの独立パネル追加も選べます。
- 「数学」から関数・微分・積分・極値・交点・変換と、パラメータースライダーを追加します。「解析」では回帰・平滑化・接線・残差表／プロットを使用できます。
- 「図形」「レイヤー」で図形・ベジェ曲線・テキストを作成します。Shift で複数選択、ドラッグ移動、整列・グループ化・重なり順・閉じたベジェを含む図形演算・面積計算・ロック・表示切替ができます。右クリックにはオブジェクト操作メニューがあります。
- 「文字」から LaTeX 数式を追加できます。`x^2`、`t_1`、`Delta`、`alpha` などの簡易入力にも対応します。
- グラフの細部は「座標軸」「プロパティ」で編集します。「設定」でフェードインを設定・再生できます。

## 計算と保存

標準の表編集にはFortune Sheet（表示メニューの「表を詳細編集」）を使い、セル・数式・書式を同じプロジェクトへ同期します。数式の関数計算に FormulaJS、行列・記号微分に mathjs、原始関数に Nerdamer を使用します。セル参照・依存関係・構造変更はアプリで管理します。Univerは技術候補の一つで、採用したエンジンはFortune Sheetです。

中央差分、Simpson法、台形則、記号微分・解析的積分を区別します。回帰は最小二乗法、任意モデルの非線形回帰は Levenberg–Marquardt 法です。接線は隣接点差分・局所線形近似・平滑化後・2次回帰を選べます。幾何学面積の単位はキャンバス座標の %² です。計算は JavaScript の倍精度であり、任意精度・厳密解の保証はありません。

作業はブラウザーの localStorage に保存します。Undo/Redo のスナップショットも、上限60操作でプロジェクトと一緒に保持します。別端末への移動・バックアップには `.plot.json` をダウンロードしてください。アカウント・クラウド同期・共同編集は含みません。

## 入出力

- CSV・TSV・XLSX・Plot プロジェクトの読み込み／書き出し。
- XLSX: 複数シート、数式・共有数式、数値・文字、基本書式・結合、基本グラフ7形式のネイティブ出力。Excelの全関数・書式・グラフの完全互換ではありません。
- アプリが出力したXLSXには拡張グラフモデルも保持します。他ソフトで再保存すると拡張情報が削除される場合があるため、完全な再編集にはPlot形式を使用します。
- SVG・PNG・ベクターPDF。PDFは印刷ダイアログを使わずダウンロードします。LaTeXと日本語を含む文字をパスへ変換し、出力先のフォントに依存しない描画にします。
- 出力プリセット・Custom寸法・倍率・DPI・余白・フォント・背景透明・sRGB/グレースケールを選択できます。PDFではDevice CMYKと、LittleCMSによる任意のRGB/CMYK/Gray ICCプロファイルへの変換・出力プロファイル埋込みにも対応します。ICCファイルは出力時に選択します。CMYK/ICC管理はPDF用で、SVG/PNGはRGB形式です。
- 出力用 Noto フォントとライセンスは `assets/` に同梱しています。BMPの範囲外など、同梱フォントにない文字は保証しません。

## 本番相当の検証

```bash
npm run test:deployment
```

Workersローカルを自動起動し、初回起動・基本操作・追加機能・実デプロイ用アセット・ICC PDF・起動失敗からの復旧を検証します。通常の開発サーバーだけの確認ではありません。

## 検証

```bash
npm test
npm run check
npm run build
```

サーバーを起動した状態で、別端末から次を実行します。

```bash
npm run test:browser
```

ブラウザーテストは `/usr/bin/chromium` を使用します。`CHROMIUM_PATH`・`APP_URL` を指定できます。テストには表計算操作、解析、テーマ、保存復元、CSV/XLSX、SVG/PNG/PDF、無彩色UI、図形・LaTeX・パネル配置・仮想スクロールを含みます。スクリーンショットは `test-results/` に保存します。

仕様との対応と具体的な制限は [仕様対応表](docs/SPEC-COVERAGE.md) を参照してください。
