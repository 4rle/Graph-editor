# Plot — 表計算と Graph Studio

「最強グラフエディタ搭載表計算ソフト仕様書」v1.0 を基にした Web アプリの初期実装です。表計算と専用グラフ編集画面で同じデータを共有し、セルの変更をグラフ・数学オブジェクトへ反映します。

仕様書の全機能が完成した製品ではありません。実装済み・一部対応・未対応の範囲は [仕様対応表](docs/SPEC-COVERAGE.md) に記録しています。

## 起動

Node.js 22 以降が必要です。実行時の外部パッケージ依存はなく、依存関係のインストールやビルドは不要です。

```bash
cd /workspace/Graph-editor
npm start
```

開発サーバーはポート `5173` を使用します。別のポートで起動する場合は `PORT=5180 npm start` を実行してください。`npm run dev` も同じサーバーを起動します。画面を変更した後はブラウザーを再読み込みします。

## 主な操作

- **表計算**: 数値・文字・数式の編集、セル参照、範囲選択、コピー＆貼り付け、オートフィル、書式、シート管理、並べ替え、フィルター、検索・置換、Undo・Redo。
- **Graph Studio**: 11種類のグラフ、系列色、軸範囲、対数Y軸、凡例・点・ラベル、12テーマとカスタムテーマ、注釈、表示系列の切り替え。
- **数学・解析**: 関数曲線、接線・法線、定積分の数値計算、データ点と連動する原点線分・垂線・座標ラベル、差分接線、線形・多項式・指数回帰、決定係数、基本統計。
- **ファイル**: CSV・TSV・XLSX・独自プロジェクトの読み込み、SVG・PNG・CSV・TSV・XLSX・プロジェクトの書き出し、ブラウザー印刷によるPDF保存。

グラフのデータ範囲は **1行目を系列名、1列目をX値またはカテゴリ** として解釈します。空白・文字のY値は数値点から除外します。数式は `=SUM(B2:B13)`、`=IF(B2>50,"高","低")`、`=AVERAGE('実験データ'!B2:B13)` などに対応します。Excelの全関数互換ではありません。

グリッドは60行×20列のウィンドウで表示し、下部の矢印や名前ボックスから別の範囲へ移動できます。全セルを仮想スクロールする方式ではありません。

セルはダブルクリック、F2、または文字入力で編集できます。Enter・Tab・矢印で移動し、Shift＋クリック／ドラッグで範囲を選択します。オートフィルは先頭セルを含む範囲を選び、選択セル右下のハンドルを押します。

## 保存と互換性

作業内容は、このブラウザー・このオリジンの `localStorage` に自動保存します。サーバーのデータベース、アカウント、クラウド同期、共同編集はありません。ブラウザーの保存領域を削除すると自動保存も消えます。

別端末への移動やバックアップには「エクスポート → Plot」から `.plot.json` を保存してください。プロジェクトにはシート、数式、グラフ設定、数学オブジェクト、カスタムテーマ、保存したワークスペース、編集履歴のラベルを保持します。Undo用の全スナップショットは現在のセッション内にのみ保持します。

XLSXでは、複数シート、数値・文字、数式、基本的な太字・文字色・背景色・配置・数値書式を読み書きします。Excel内のグラフ、日付シリアル値の表示解釈、テーマ／インデックス色、複雑な書式は完全互換ではありません。完全な再編集にはPlot形式を使用してください。

画像出力ではPresentation・Scientific Paper・Poster・Social Media・Printの寸法プリセットと倍率を選べます。カラープロファイルや印刷用の厳密な余白・実寸管理は未対応です。

数学処理はJavaScriptの倍精度数値計算です。関数の微分は中央差分、関数の積分はSimpson法、離散データの積分は台形則を使用します。記号微分・解析的積分を実装したものではありません。

## 検証

```bash
npm test
npm run check
```

`npm test` はセル参照・計算・構造変更、数学計算、グラフ描画とデータ連動、CSV／XLSX／プロジェクト入出力、入力検証のテストを実行します。Nodeの標準テストランナーを使用します。

ブラウザーで一連の操作を検証する場合は、別の端末でサーバーを起動したまま次を実行します。

```bash
npm ci
npm run test:browser
```

ブラウザーテストだけが開発依存の Playwright を使用します。既定の Chromium は `/usr/bin/chromium` です。必要に応じて `CHROMIUM_PATH`、検証先を `APP_URL` で指定してください。スクリーンショットは `test-results/` に保存します。

手動で確認する際は、次の順序が基本のフローです。

1. 初期データの `B2` を変更し、シート上のグラフが変化することを確認する。
2. 空セルに `=SUM(B2:D2)` を入力し、Undo・Redoを試す。
3. 「Graph Studio」を開き、テーマ・系列色・軸ラベルを変更する。
4. 「解析」で回帰曲線を追加し、「数学」で関数・接線・積分領域を追加する。
5. 元のデータを変更し、描画と解析結果が再計算されることを確認する。
6. SVGまたはPNGを書き出し、Plot形式で保存・再読み込みする。
7. CSV／XLSXを読み込み、シートと数式・書式を確認する。

## 実装構成

| ファイル         | 役割                                               |
| ---------------- | -------------------------------------------------- |
| `src/app.js`     | 画面、操作、プロジェクト状態、自動保存、Undo／Redo |
| `src/engine.js`  | 安全な数式パーサー、セル参照、数値微分・積分・回帰 |
| `src/chart.js`   | SVGグラフ、数学オブジェクト、デザインテーマ        |
| `src/io.js`      | CSV／TSV、XLSX、プロジェクト入出力と検証           |
| `src/styles.css` | 通常画面、Studio、レスポンシブ表示、印刷           |
| `server.js`      | Node標準ライブラリによるローカル開発サーバー       |

仕様書のReact・Univer・FlexLayout・math.js・KaTeX・D3などは技術候補です。この初期実装はES ModulesとブラウザーAPIを使用し、既存の表計算エンジンをまだ導入していません。仕様書の「既存エンジンの活用を優先」という方針との差分であり、高度なExcel互換性・大規模ブック対応と合わせて残る開発項目です。
