# テーマの描画ルール

テーマは配色を含むデザイン一式です。`src/theme-design.js` に形状・線・文字・レイアウトを定義し、通常グラフ・複合グラフ・等高線の描画で共有します。48プリセットを13種類の表現から組み立て、プリセットごとの差分を設定しています。

| 代表的なテーマ                | 形と線                                              | 文字・空間・背景                                                 |
| ----------------------------- | --------------------------------------------------- | ---------------------------------------------------------------- |
| Flat Design                   | 3pxの実線、塗りつぶした点、角のある棒、影なし       | サンセリフ、明快な見出し、水平グリッド                           |
| Kawaii Minimal                | 4.6pxの丸線、大きな輪郭付きの点、角丸14pxの棒       | 丸みのある書体、広い余白、丸い描画面、ピル形の凡例、点線グリッド |
| Scientific Minimal            | 1.6pxの細線、中抜きの丸・四角・ひし形、内向き目盛り | 小さく精密な文字、左と下の軸、コンパクトな配置                   |
| Technical Drawing / Blueprint | 細線、四角の点、両方向グリッド、補助目盛り、外枠    | 等幅文字、密度の高い配置                                         |
| Editorial Design              | 控えめな線、点とグリッドを省略                      | 大きな明朝の見出し、罫線、広い余白、四角の凡例                   |
| Bauhaus                       | 5pxの線、四角の点、太い軸、幾何学的な形             | 太い見出し、影を使わない色面                                     |
| Glassmorphism                 | 丸い線と棒、半透明の描画面                          | ガラス面、控えめな影、背景グラデーション                         |
| Neo-Brutalism / Comic Style   | 太い輪郭、強い線、輪郭付きの点                      | 太い見出し、オフセットした硬い影                                 |
| Cyberpunk                     | 光彩付きの線、中抜きの点、外枠                      | 等幅文字、暗い背景、細かいグリッド                               |
| Pixel Design                  | 角のある線、四角の点、ドット向け描画                | 等幅文字、グリッド、影なし                                       |
| Risograph / Hand-Drawn        | 印刷を意識した線、点、面の濃度                      | 紙の粒状パターン、控えめな破線グリッド                           |

数値は標準サイズのSVGでの値です。小さいプレビューでは形や文字も縮小します。

切り替え時は、前のテーマや手動編集の線幅・余白・フォントなどを置き換えます。その後、個々の設定を調整できます。「テーマの構成要素」ではStyle・Palette・Typography・Layout・Chart Elements・Backgroundを組み合わせられます。Styleの変更でも、前のStyleの形状設定が残らないようにしています。

データ・数式・数学オブジェクト・軸の数値範囲は保持します。線を滑らかに見せるための補間やデータの変形は行いません。保存したカスタムテーマには、線幅だけでなく点・余白・表示設定・構成要素も含めます。プレビュー、キャンバス、SVG/PNG/PDFは共通の描画を使用します。

`tests/themes.test.js` は同じ配色での形の差、全テーマの複数形式、データ保持、カスタム保存を検証します。`tests/browser-themes.mjs` は実際の切り替え・保存復元・SVG出力を操作し、`test-results/theme-*.png` に比較画像を保存します。
