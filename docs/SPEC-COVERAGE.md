# 仕様書 v1.0 対応状況

対象は添付された「最強グラフエディタ搭載表計算ソフト仕様書.pdf」です。これは現時点の実装範囲を示す表であり、全Phaseの完了宣言ではありません。

「対応」は記載した範囲の実装があること、「一部」は制限・未実装の要件が残ることを表します。

## ワークスペースと表計算

| ---------------------------------------------------------------------------- | ------ | ---------------------------------------------------------------------------------------------------------------------------------- |

## 続く開発で優先する項目

1. 既存の表計算エンジン導入と大規模ブック・Excel互換性の検証。
2. パネルの完全なドック／タブ／最大化とキャンバスのオブジェクト編集基盤。
3. KaTeXによる数式組版と、交点・極値・幾何学面積などの数学機能。
4. 複合軸・媒介変数・極座標・等高線、平滑化・残差分析の専用UI。
5. テーマ要素の組合せ、全プリセット、出力プリセットとカラープロファイル。
