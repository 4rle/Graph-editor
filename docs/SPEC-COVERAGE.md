# 仕様書 v1.0 対応状況 — 0.2

今回の明示指定に従い、ヘッダー・ロゴ・各タブの装飾的な見出しと文章を削除。Graph Studio の UI は無彩色のダークテーマへ変更した。グラフそのもののテーマ色は保持する。

「対応」はこの表で説明する操作が利用できることを示す。Excelやプロ向け制作ソフトの全機能・完全な互換性を意味しない。

## 残る実装・互換性の境界

仕様書の機能分類は広く実装したが、上記の制限があるため「すべての仕様を完全に実現した」とは扱わない。特に、既存の完成した表計算UIへの置換、Excelの全要素・特殊グラフの相互互換、任意ICC/CMYK、任意ベジェ面のブーリアン演算、プロ用ソフトと同等の自由なパネル分割は追加開発が必要である。
