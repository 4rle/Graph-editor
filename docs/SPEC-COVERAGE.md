## 今回完了した残項目

- 既存表計算エンジンの導入: Fortune Sheet。編集結果をセル・数式・書式・シートへ同期。
- 閉じたベジェ面の演算: Paper.js。曲線を多角形へ置き換えずSVGパスとして保持。
- 独立パネルと自由な分割: 個別追加、上下左右ドック、タブ、フロート、保存・復元。循環配置検証。
- カラープロファイル: LittleCMSによるICC色変換、PDF出力プロファイル埋込み、CMYK描画命令を検証。
- データ点の直接編集: 元セルの更新と再計算、Shift複数選択、AltでX座標更新。
- 本番配信: 独立したdist、Workers設定、初回起動と障害時の復旧UIを実ランタイムで検証。

## 確認方法と定義

`npm test` は数学・参照・図形・互換性・配信物を検証し、`npm run test:deployment` は本番配信するdistをWorkersローカルで起動して実操作を検証する。XLSXについては仕様書2.6の「段階的に検証」に従い、数式・書式・複数シートと基本グラフ7種を確認している。Excelという別製品の全機能・全バージョンの完全互換を意味しない。

計算精度・原始関数の存在・回帰の局所最適・フォント収録文字・ブラウザー保存容量には各処理方式の境界がある。これらを隠して厳密解・任意精度・無制限容量を保証するものではない。SVG/PNGはRGB画像であるため、CMYK/ICC出力はPDFで選択する。
