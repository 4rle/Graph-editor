# 表計算 / Graph Studio UI

最新ユーザー指定を優先する。

- ヘッダー・ロゴを表示しない。メニュー行にファイル名・保存・切替・入出力を集約する。
- Graph Studio の UI は彩度0。背景 #1e1e1e、操作面 #292929/#333333、境界 #555555、文字 #ddd/#aaa。色のあるチャートや色ピッカーは作品・データの意味として保持する。
- タブの英語ラベル・キャッチコピー・装飾説明は入れない。項目名・計算方法・入力条件を必要な場所に表示する。
- 白い表計算画面と暗いStudioを切り替え、中央の作業面を広く保つ。
- 画面全体のスクロールを避け、表・パネルを内部スクロールする。狭い横画面では補助パネルを閉じてグラフ全体を収める。
- 編集パネル・属性・データはドック／タブ／フロート／非表示／最大化。配置を保存・復元できる。
- 844×390、932×430、740×360、390×844、1440×900で検証する。
