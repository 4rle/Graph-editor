# Plot デザインシステム

目的は、表のデータからグラフを作り、同じデータを見ながら仕上げること。
「精密・静穏・創造的」を基調とする。白い表計算画面とチャコールの専用スタジオを切り替え、主役の作業領域を広く取る。

- アクセント: emerald #147d66。文字 #243632、補助 #667570、境界 #dfe6e2、操作面 #fff、背景 #f4f7f5。
- スタジオ: #202927 / #293430。グラフの白い紙面と区別する。
- 日本語: Noto Sans JP が利用可能なら使用、Hiragino Kaku Gothic ProN / Yu Gothic / system-ui。数値は等幅数字。
- 余白: 4 / 8 / 12 / 16 / 24 / 32 px。角丸: ボタン6px、ダイアログ12px。グリッドには丸みを付けない。
- 上部: ファイルと保存状態、ワークスペース切替。次にメニュー、ツールバー、数式バー。
- 表計算: 列・行ヘッダー、編集グリッド、シートタブ、選択範囲集計。グラフはシート上のオブジェクト。
- スタジオ: 左ツール、文脈パネル、中央キャンバス、右インスペクター、下部データ。
- 画面が狭い場合はインスペクターを畳み、ツール・データは必要時に表示する。横画面844x390を含め低い高さでは内部スクロールを許す。
- キーボード: Enter/Tab/矢印、Shift範囲選択、コピー＆ペースト、Ctrl/Cmd+Z、検索。全操作には名前とフォーカス表示を付ける。

UI/UX Pro Max同梱検索はクラウドスキルのスクリプトが実行環境へ展開されておらず利用不可。上記は仕様書と polished-app-ui に基づく設計判断。
